## Controller Mapper
A keybinder for a nintendo switch controller to be able to type using it.

### Motivation
I built this project to refresh my memory on python by doing a fun and unique project which can't be copied from any tutorial online

### Technologies
Python 3.14.0

### System Flow
1. User uses R button tocycle through different letters
2. Player moves joystick towards letter or choice
3. Key is typed

### Keybinds
    'ZR': Selection,
    'ZL': AltBTN
    'L': CopyPaste
    'R': Counter
    'X': Tab
    'A': Space
    'Y': Backspace
    'B': Enter
    'Arrow buttons': Navigation
    'Left joystick': Letters
    'Right joystick': Symbols and numbers(Alt)
    '+ button': Undo and redo(Alt)
